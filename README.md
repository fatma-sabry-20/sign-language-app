# 🤟 مترجم لغة الإشارة — تطبيق كامل (سيرفر + قاعدة بيانات)

## تشغيله في 3 خطوات

1. نزّل **Node.js** النسخة 22 أو أحدث من nodejs.org
2. افتح الـ Terminal داخل فولدر المشروع واكتب:
   ```
   npm install
   npm start
   ```
3. افتح المتصفح على **http://localhost:3000** وسجّل حساب جديد.

أول تشغيل: السيرفر بينزّل موديل تتبع اليد (~8MB) لوحده، فلازم يكون فيه إنترنت.
للتأكد إن الكود شغال: `npm test` (37 اختبار تلقائي).

## الملفات (5 ملفات بس)

| الملف | وظيفته |
|---|---|
| `server.js` | السيرفر: كل الـ API (حسابات، أهل، طوارئ، إشارات) |
| `db.js` | قاعدة البيانات (SQLite) وإنشاء الجداول وقاموس الإشارات |
| `public/index.html` | الواجهة (نفس تصميمك) وبتكلم السيرفر |
| `public/sign-core.js` | محرك التعرف على الإشارة (تطبيع + kNN + مثبّت) |
| `test.js` | اختبار تلقائي |
| `.env.example` | الإعدادات الاختيارية (SMS والموديل) |

قاعدة البيانات بتتعمل لوحدها في فولدر `data/` أول ما تشغّل. **خد نسخة احتياطية من الفولدر ده**.

## الطوارئ: إزاي بتبعت فعلاً؟

- **من غير أي إعداد:** التنبيه بيتسجل، وبيظهر لكل شخص زر **واتساب** برسالة جاهزة فيها اسمك ورابط موقعك على الخريطة. المستخدم بيضغط الزر ويبعت.
- **SMS تلقائي بالكامل:** اعمل حساب على Twilio، وحط المفاتيح الثلاثة من `.env.example` في ملف `.env` (أو في إعدادات الاستضافة). السيرفر هيبعت SMS لكل الجهات لوحده. ده بيتكلف فلوس حسب الرسايل.

⚠️ لأنه تطبيق طوارئ فعلاً: جرّبه مع أرقام تعرفها قبل ما حد يعتمد عليه.

## إزاي التعرف على الإشارة بيشتغل (حقيقي، من غير محاكاة)

مفيش موديل جاهز دقيق للإشارة العربية/المصرية، فالتطبيق **بيتعلّم منك** إنتِ:

1. **MediaPipe** (من جوجل) بيتتبع اليدين في الكاميرا وبيطلّع 21 نقطة لكل يد، كله جوه المتصفح (الفيديو مش بيتبعت لأي سيرفر).
2. من تاب الكاميرا اختاري **«تعليم إشارة جديدة»**، اكتبي معنى الإشارة، اضغطي «سجّل» وأدّيها 3 ثواني. بتتحفظ في قاعدة البيانات على حسابك.
3. في وضع **«ترجمة»** التطبيق بيقارن إشارتك الحالية بالإشارات المحفوظة (خوارزمية kNN) ولما تثبت حوالي نص ثانية بيكتبها وتتجمّع جملة، وتقدري تخليه ينطقها بصوت.

**حدود لازم تعرفيها بصراحة:**
- بيتعرف على **وضعيات اليد الثابتة** (حروف، أرقام، كلمات إشارتها وضع ثابت). الإشارات اللي فيها **حركة** (زي «شكراً» الحقيقية) لسه مش مدعومة، لأنها تحتاج تحليل تسلسل فريمات.
- الدقة بتعتمد على كمية وتنوّع اللي سجّلتيه (سجّلي كل إشارة 2–3 مرات بزوايا مختلفة). ومحتاجة إضاءة كويسة.
- هي مش «مترجم عام» لأي شخص بيتكلم لغة الإشارة؛ هي بتتعرف بس على إشاراتك إنتِ. العينات بتتحفظ على كل حساب لوحده.
- شريط **«حساسية التعرف»** بيظبط مدى التشابه المطلوب. لو بيكتب كلمات غلط قلّليه، ولو مش بيعرف إشارتك زوّديه. **ماجرّبتش التتبع على كاميرا حقيقية هنا (بيئة العمل ملهاش كاميرا)، فجرّبيه وقوليلي النتيجة عشان نظبطه.**

## توسيع قاموس الإشارات

الإشارات الحالية 18 كلمة بس، وأوصاف الحركات مكتوبة بشكل مبدئي. لازم حد يعرف لغة الإشارة يراجعها. لإضافة كلمة، ضيف سطر في قائمة `seed` داخل `db.js` (كلمة، رمز، وصف).

## نشره على الإنترنت

محتاج استضافة بتشغّل Node.js (Render أو Railway أو VPS). ضروري:
- يكون عليه **https** (الكاميرا والموقع مش بيشتغلوا من غير https).
- حط `NODE_ENV=production`.
- فولدر `data/` لازم يكون على تخزين دائم، وإلا قاعدة البيانات بتتمسح مع كل تحديث.

## الـ API باختصار

| الطلب | الوظيفة |
|---|---|
| `POST /api/auth/register` `login` `logout` | الحساب |
| `GET /api/me` | بياناتي |
| `GET/POST /api/contacts`، `DELETE /api/contacts/:id` | جهات الطوارئ |
| `POST /api/sos` | إرسال طوارئ (`lat`, `lng` اختياري) |
| `GET /api/sos/history` | آخر التنبيهات |
| `POST /api/text-to-sign` | نص إلى إشارات |
| `GET/POST /api/samples`، `GET /api/samples/labels`، `DELETE /api/samples/:label` | الإشارات اللي علّمتيها للتطبيق |
| `POST/GET /api/translations` | سجل الكلمات اللي اتعرّف عليها |
